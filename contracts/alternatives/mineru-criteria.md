# MinerU 표본 시험 사전 판정 기준

2026-11-13, 변환 실행 전 고정. LSR 1.1 북마크/무북마크 13쪽과 NIST 발췌 11쪽만 대상이다. 고정 Docling 권장 pdf-en-v2 결과와 같은 채점 규칙으로 비교한다.

MinerU 전환 추천은 다음을 **모두** 검증했을 때만 한다.

| 기준 | 충족 조건 |
| --- | --- |
| a | 표 내용·숫자 보존이 Docling보다 뚜렷이 낫거나, 같으면서 수식이 뚜렷이 낫다 |
| b | 숫자·부호·단위 보존이 Docling보다 나쁘지 않다 |
| c | 블록 단위 쪽·좌표가 있어 원문 대응 파일을 만들 수 있다 |
| d | 북마크 판 제목 계층이 Docling 16/17보다 나쁘지 않거나 PDF 북마크 별도 읽기로 단순 보완할 수 있다 |
| e | 머리글·바닥글·쪽 번호가 본문과 구분된다 |
| f | 동일 입력 두 번의 구조·내용·좌표가 실질적으로 같다. 작업 ID·시각 등 부수 메타데이터 제외 |
| g | 라이선스·설치 조건에 내부 PC 사용의 명백한 걸림이 없다 |

하나라도 실패하거나 검증하지 못하면 **Docling 유지**. 미측정을 품질 실패나 0점으로 표시하지 않는다. 수식 등 부분 개선은 별도로 기록한다. 숫자 missing/extra는 오류 확정 수가 아닌 검토 후보다. 수식 literal과 시각 의미 판정을 구분한다. 대조 불가 항목은 명시하고 규칙을 바꾸면 Docling에도 동일 적용한다.

기존 mineru-api만 사용하고 새 이미지·모델 다운로드·컨테이너 생성·설정 변경은 하지 않는다. 127.0.0.1 전용 접근 조건을 충족하지 못하는 기존 설정이면 시작하지 않고 실행 불가로 기록한다. Docling 서버는 시작하지 않는다. 원본 변환 결과는 저장소 밖에 보존하고 요약 JSON만 커밋한다.
