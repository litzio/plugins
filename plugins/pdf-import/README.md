# PDF 가져오기

글자 층이 있는 PDF를 리치오 문서로 만들고, 원본 쪽과 저장된 문서를 나란히 봅니다. 변환 서버와 AI 모델은 쓰지 않습니다.

## 설치와 사용

Node 24 환경에서 이 폴더의 `npm ci --omit=optional`를 실행합니다. `node prepare.mjs`는 고정된 pdf.js worker 문자열을 다시 만듭니다. 공식 CLI에서 대상 Host를 명시하여 `litzio plugins install <이 폴더> --host <Host 주소> --json`으로 설치합니다.

PDF가 든 폴더를 리치오에서 열고 **PDF 가져오기 → PDF 고르기**로 파일을 고릅니다. 바로 변환하며 같은 폴더에 같은 이름의 `.md`와 `.pdf-source.json` 대응 자료, `assets/`의 그림을 만듭니다. 이전·다음은 경고만 순회하고 원본 상자를 누르면 문서 블록을 강조합니다. 문서 열기는 일반 탭을 엽니다.

첫 화면의 **변환한 문서** 행을 고르면 PDF를 다시 고르지 않고 저장본을 엽니다. 목록은 이 브라우저가 Host별로 기억한 최근 10개 PDF 폴더의 대응 자료를 읽으며 하위 폴더와 이전 사본은 찾지 않습니다. 원본이 없거나 바뀌면 상태를 표시하고 자동 변환하지 않습니다. 같은 이름은 폴더 이름 하나로 구분합니다. 새 PC나 브라우저 자료를 지운 뒤에는 그 폴더에서 PDF를 한 번 고르기 전까지 목록이 비어 있습니다. 공개 계약에 현재 열린 폴더를 조회하는 기능이 없어 최근 폴더 방식을 사용합니다.

첫 번호 제목 이전 쪽은 원본에 **변환에서 제외 · 본문 시작 전** 표시와 대상 정보의 제외 범위를 보여 줍니다. 표시의 hover·키보드 focus에서 제외 이유를 확인합니다.

동일 PDF의 저장본은 다시 사용합니다. 다시 변환은 확인 후 기존 문서와 대응 자료를 같은 폴더의 `previous` 사본으로 보관하고 새 문서를 만듭니다. 이전 그림은 삭제하지 않습니다. 문서를 고쳤으면 대응 이동을 막습니다. 대응 자료를 잃은 기존 문서는 자동 덮어쓰지 않습니다.

짝이 맞는 각주는 공식 미주로 저장합니다. 정의 없는 표시는 `[n]` 글자로, 표시 없는 정의는 해당 쪽의 문단으로 보존하고 경고합니다. 표·그림은 원본 영역 PNG이고 캡션은 작성 입력의 그림 캡션을 사용합니다. 인식할 영역이 없는 독립 캡션은 문단으로 남습니다. 캡션은 Table/Figure 번호 뒤의 줄표·하이픈·마침표·쌍점을 인식하며, 보통 글자는 같은 쪽의 인접 영역이 있어야 합니다. Figure 아래 작은 글자의 축 줄만 사이에 있으면 영역을 아래로 넓혀 PNG에 포함합니다. 본문 크기의 줄을 넘어서 연결하지 않습니다.

## 확인 범위

`npm test`는 리치오 없이 공개 LSR 표본의 제목·글자 분류·제외·쪽 간 문단·결과 형태, 짝 없는 표시, 영역 합치기와 각주 공백 보존, 캡션과 축 포함, 같은 크기 각주 번호·쪽 간 짝 맞추기, 최근 폴더 목록의 원본 변경·삭제를 검사합니다. 실제 격리 HTTP Host에서 공개 표본과 별도 큰 디지털 PDF의 선택·변환·저장·강조·전체 스크롤을 확인했습니다. 저장본 재사용, 확인 후 이전 사본 보관, revision 변경 시 이동 차단, 640px 안내와 밝고 어두운 테마를 확인했습니다. 공개 표본 캡처는 `test/captures/`에 있습니다.

OCR, 스캔 PDF, 표의 문자화, 문서 교정, 옵션과 설정 화면은 없습니다. 패키징된 Desktop, 다른 OS·폰트·회전/세로쓰기 PDF, 변환 중 종료 뒤 복구는 검증하지 않았습니다. 같은 쪽에서 크게 겹치는 영역은 읽기 순서와 무관하게 하나로 합치고, 그 밖의 연속 도형은 본문·제목·캡션·각주가 경계가 됩니다. 공개 표본에는 영역 밖 축 글자의 본문 혼입, 옆에 놓인 표의 합침, 수식 도형과 본문의 분리, 작은 글자 본문의 각주 포함이 남아 있습니다. 이 변경은 그 부분을 교정하지 않습니다. 원문 각주 번호와 리치오가 표시하는 미주 번호는 다를 수 있습니다. 저장본을 불러올 때 revision을 확인하고 이후 stale-target 알림이 오면 이동을 막습니다.

직접 의존성은 Apache-2.0의 `pdfjs-dist` 6.5.438 하나입니다. pdf.js worker와 `PDFJS-LICENSE`는 같은 배포물에서 가져옵니다. 스크립팅은 계속 끕니다. `npm audit`에서 취약점 0건을 확인했습니다.

`npm ci --omit=optional` 설치 상태에서 추출과 검사를 실행했습니다. 선택적 canvas와 그리기 전역에 관한 pdf.js 경고는 나지만 글자·도형 추출에 사용되지 않아 전역 대체는 추가하지 않았습니다.

`node measure.mjs <PDF>`는 문서를 저장하지 않고 추출·규칙을 실행해 제목·각주·캡션 등의 검증 통계를 JSON으로 출력합니다. 저작권 입력의 통계와 내용은 저장소 밖에서만 보관합니다.
