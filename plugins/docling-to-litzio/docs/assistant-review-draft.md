# 비서 검수 스킬

PR 4-가의 본문 초안을 PR 4-나에서 실제 설치되는 [skills/review/SKILL.md](../skills/review/SKILL.md)로 다듬었다. 본문과 명령의 정본은 그 파일이다. manifest skills.id는 짧은 `review`이며, 설치 namespace 이름은 47자다.

공개 작업 자료 → PDF 근거 대조 → 교정 제출 또는 uncertain → 후 값/revision/재대조 확인 → 실제 검사 범위 checkpoint 순서다. 정상 값을 바꾸지 않고, 수식/구조 의미를 token 일치로 확정하지 않는다. 불확실한 쓰기는 자동 재전송하지 않으며 공개 중단/재개 작업을 사용한다.

실제 비서 수락의 범위와 막힌 점은 results-assistant-skill.md에 기록한다. 한 번의 수락을 AI 교정 품질 보증으로 쓰지 않는다.
