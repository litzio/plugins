## E · 공개 에이전트 도구 검증 후 사용할 선택 시나리오

현재 프로젝트·릴리즈·Baseline을 지정하고 “검증되지 않은 시스템 요구사항을 근거와 함께 정리해줘”라고 요청한다. 플러그인 읽기 작업이 조회한 실제 ID, 대상 리비전, 원문 위치와 검증 누락 이유를 출력한다. 화면에서 대상 ID를 열고 개선 조치 초안을 사람이 검토·확정한다. 읽기 도구 호출과 보고서 작성의 실제 결과를 Phase 4에서 확인한 후 시연 구성에 포함한다.
