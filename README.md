# Litzio plugins

[리치오](https://github.com/litzio/litzio) 위에서 도는 플러그인을 두는 공개 저장소다. 라이선스는 MIT(`LICENSE`)이며, 포함된 제3자 코드와 표본은 각자의 라이선스 파일을 따른다.

첫 플러그인 [PDF 가져오기](plugins/pdf-import/README.md)를 만든다. 첫 시도는 2026-11-16에 지웠고, 하나씩 다시 만든다. 다시 만들기 전에 [첫 시도의 교훈](docs/lessons.md)을 읽는다. 만들면서 리치오 쪽에서 막힌 것은 [리치오에 모자란 것](docs/platform-gaps.md)에 적는다. 지운 내용은 태그 `archive/2026-11-16-first-attempt`에 있다.

[워드 가져오기](plugins/word-import/README.md)는 워드 문서(.docx)를 리치오 문서로 옮기고 옮기지 못했거나 바꿔 적은 곳을 목록으로 보여 준다.

[메일 열람](plugins/mail-viewer/README.md)은 메일 파일(.eml)을 열어 제목, 사람, 날짜, 본문과 첨부 목록을 보여 주는 파일럿이다.

작업 규칙은 [AGENTS.md](AGENTS.md)에 있다.
