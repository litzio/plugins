# Litzio plugins

[리치오](https://github.com/litzio/litzio) 위에서 도는 플러그인을 두는 공개 저장소다. 라이선스는 MIT(`LICENSE`)이며, 포함된 제3자 코드와 표본은 각자의 라이선스 파일을 따른다.

[문서 가져오기](plugins/document-import/README.md)는 PDF와 워드 문서(.docx)를 리치오 문서로 옮기고 원본과 결과를 나란히 보여 준다. 첫 시도의 교훈은 [다시 만들기 기록](docs/lessons.md)에, 플랫폼에서 막힌 점은 [리치오에 모자란 것](docs/platform-gaps.md)에 적는다. 첫 시도의 코드는 태그 `archive/2026-11-16-first-attempt`에 있다.

[메일 열람](plugins/mail-viewer/README.md)은 메일 파일(.eml)을 열어 제목, 사람, 날짜, 본문과 첨부 목록을 보여 주는 파일럿이다.

작업 규칙은 [AGENTS.md](AGENTS.md)에 있다.
